Hostile corpus and sample feeds for the tests (SPEC §14).

Every file here was written for this project as synthetic test data, under the project's license
(MPL-2.0). None of it is copied from a real feed or real show notes. Hosts are example.com,
example.org and the reserved .test domain.

The files carry no license comment, because a comment before the XML declaration or a byte order
mark would change what the tests exercise.

corpus/feeds   one test per file in :core:feed (HostileFeedCorpusTest)
corpus/opml    one test per file in :core:feed (OpmlParserTest)
corpus/notes   show-notes sanitizer inputs (ShowNotesTest)
samples/feeds  ordinary feeds that mimic common publisher patterns (FeedParserTest)
samples/opml   ordinary OPML exports (OpmlParserTest)

Fixtures that need exact bytes (UTF-16, Latin-1, raw control characters) or are too big to commit
(25 MB, 10,000 items, 65-deep nesting) are generated by SyntheticFeeds in this module.
